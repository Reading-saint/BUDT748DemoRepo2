# BUDT748 Sample IS Course Site

A three page website (Homepage, About, Contact) designed in Figma and built with HTML, CSS and Bootstrap 5.3, published with GitHub Pages.

## Structure

```
index.html      Homepage
about.html      About page
contact.html    Contact page
css/
  styles.css    Homepage styles
  styles2.css   About page styles
  styles3.css   Contact page styles
images/         Exported Figma assets
```
